# Scripts SQL

Una carpeta por motor (`DB_CLIENT` en `.env`): `mssql/` y `postgres/`. Las dos tienen
la misma estructura y los mismos nombres de archivo:

```
setup/       (solo mssql) crea BD + login; corre como DB_ADMIN_USER contra master
tables/      una tabla por script, numeradas (01_, 02_ ...)
seeds/       datos base
views/ triggers/ procedures/ indexes/   (crearlas si hacen falta; corren en ese orden)
migrations/  cambios para BD con datos (npm run db:migrate; db:setup no la ejecuta)
```

`npm run db:setup` (`scripts/run-sql.js`) ejecuta las carpetas en ese orden, cada una
por orden alfabético de archivo, y al final crea el usuario admin. Todo script debe
ser idempotente (`IF OBJECT_ID(...) IS NULL` / `CREATE TABLE IF NOT EXISTS`).

Al agregar una tabla, escríbela en **los dos** motores (o borra la carpeta del motor
que no uses). Equivalencias:

| SQL Server | PostgreSQL |
|---|---|
| `INT IDENTITY(1,1)` | `INT GENERATED BY DEFAULT AS IDENTITY` |
| `BIT` (`1`/`0`) | `BOOLEAN` (`TRUE`/`FALSE`) |
| `NVARCHAR(n)` / `NVARCHAR(MAX)` | `VARCHAR(n)` / `TEXT` |
| `DATETIMEOFFSET`, `SYSDATETIMEOFFSET()` | `TIMESTAMPTZ`, `NOW()` |
| `IF OBJECT_ID('dbo.X','U') IS NULL ...` | `CREATE TABLE IF NOT EXISTS` |
| lotes separados con `GO` | sin `GO` (el archivo va entero) |
